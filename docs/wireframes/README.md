# Dissertation Wireframe Figures

Five standalone, low-fidelity grayscale wireframe PNG figures and matching editable SVGs for Chapter 5. The screens use outlined regions and control placeholders rather than production styling. Captions are included inside each image.

| 5.12   | Inventory and Customer-Credit Interface Wireframe | `figure-5-12-inventory-customer-credit-wireframe.png` |

The examples use illustrative customer and transaction data. The controls and workflows follow the current application screens and project architecture. Rebuild the SVGs by running `python scripts/generate_wireframe_figures.py`; PNGs are raster exports for straightforward insertion into documents and slides.
